# Market Contract Auditor

Use before creating or changing any logical relationship.

1. Read the complete contract question, resolution criteria, source, cutoff time, runoff/tie/N-A treatment.
2. Never infer complement/exhaustiveness from party labels or title wording alone.
3. Produce explicit allowed truth states.
4. Attach evidence text and source/version to the relationship.
5. If any rule ambiguity can change a truth state, mark the relationship unapproved and do not trade it.
6. Run payoff truth-table tests after every relationship change.
